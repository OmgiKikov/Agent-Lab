# Цель продукта — 22 сентября 2026

Активная цель создана через goal по поручению владельца. Довести Agent Lab до единого пути: материалы → обоснованные карточки → исправление через чат/доску → принятие → прогон внешнего агента → понятные доказательства и повтор. Закрывать harness-аудит работающими изменениями, не одним отчётом.

Новое уточнение владельца: Lab применим к разным продуктам. `aigw-local` — только внешняя испытуемая система; не менять её проект, БД, Git и процессы. Убрать из Lab специальные зависимости и пилотный мусор. Исторические доказательства не выдавать за новую проверку и не уничтожать вместе с экспериментальными скриптами.

## Правила исполнения

Исходный dirty working tree сохраняется. Проверки выполняются на копии актуальных исходников в отдельном каталоге, исходный `dist` не пересобирается. Не удалять single writer/CAS, provenance, readiness, unknown cost, атомарное принятие/решение и неизменяемые run snapshots. Тестовые/живые доказательства хранить отдельно; реальные материалы только локально. Наличие зелёных unit-тестов не закрывает цель.

Архитектурное основание: `docs/harness-architecture-review-2026-09-22.md`. Предыдущий живой checkpoint: одна исправленная ready-карточка без принятия/прогона, второй исходный диалог не завершён. Он не считается новым сквозным результатом.

## Проход: команды без разбора языка

Модель больше не передаёт в `agent_lab_scenarios` сырой `patch` или `request`. Запись формулировки от имени владельца проходит без диалога только если эта формулировка дословно есть в его сообщении или уже лежит на карточке. Совпадение основ слов записью не является. Новый факт и «клиент знал заранее» по-прежнему всегда подтверждаются. Невалидный JSON генератора и судьи не чинится локально: это неудачная попытка в пределах лимита. На OpenRouter ответ этих ролей запрашивается как JSON провайдера. Общий status/stop прогона, подготовки и смысловой проверки уже сидит в `extensions/operations.ts`; долгая живая перепроверка в этом проходе не запускалась.

Свидетельства чтения лежат в `readingManifest` библиотеки: правка карточки его не сужает, проверяющий получает и статьи, на которые карточка не сослалась. Receipt смыслового задания зависит от своих карточек и статей; правка одной карточки не сбрасывает чужие полевые receipts. Наблюдение после действия агента — действие `observe` с репликой и без исходного факта. `resumePreparation` продолжает сохранённые pending-источники и отказывается повторять вызов, оборвавшийся посреди запроса. Неудачный JSON пишется в журнал как `syntax`, `schema` или `domain`.

Не отмечается выполненным: прохождение реальным Pi и сравнение качества на сохранённом baseline и кандидате. Это живые прогоны и человеческая приёмка, их не закрывают эти тесты.
