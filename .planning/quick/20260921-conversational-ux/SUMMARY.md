# Разговорный UX Agent Lab — итог

Основной интерфейс — разговор в Pi. Доска `/agent-lab` осталась дополнительным инструментом. Ядро (runner, оценщик, хранилище, блокировка, снимки) не переписывалось.

## Что изменилось

- `extensions/conversation.ts` (новый): слова владельца из сессии, полномочия правки (разговор / native-подтверждение / вопрос владельцу), ссылки на объекты словами, вывод входа целевого варианта из карточки, строки ленты, замечания проверяющего простыми словами.
- `extensions/render/feed.ts` (новый): лента — короткая строка действия, детали по `Ctrl+O`; в `details` сессии только идентификаторы и нейтральная подпись (REV-01).
- `extensions/agent-lab.ts`: `agent_lab_status`; разговорные операции `agent_lab_scenarios` (show/edit/variant/merge/split/remove/assess/accept/budget) с CAS по виденному состоянию; правка после прогона сама уходит в новый черновик; снятие и переписывание неприменимых проверок; фоновая смысловая перепроверка; `agent_lab_run` со start/progress/stop и фоновым прогоном; `agent_lab_inspect` с `failure`/`dialogue`/`compare`; `agent_lab_repeat` по названиям; ошибки простыми словами; проверка входа до вопроса о расходе; относительные пути агента.
- `src/scenario-variants.ts`: вариант, теряющий раскрываемый факт, теряет и состояния, которые стали недостижимы.
- `src/verdict.ts`: строка «Дальше» в чате предлагает попросить, а не открыть раздел.
- `skills/agent-builder/SKILL.md`, системный промпт, README, спецификация: разговорный цикл; намеренное изменение UX отмечено.

## Проверка (три вида доказательств — отдельно)

1. **Автотесты** (отдельная копия, живой `dist` не трогался): 810/810, typecheck расширений чистый. Новые: `test/conversation.test.ts` — 22 теста с реальным временным хранилищем.
2. **Модельные вызовы** (вымышленные данные, OpenRouter `openai/gpt-5.6-sol`; подписка Codex упёрлась в лимит): Lab — 67 вызовов, $0.71 по записям прогонов; модель разговора — около $1.32 по счётчику Pi.
3. **Проход в настоящем Pi (tmux)**: логи → сценарии → источник → правка ответом владельца → синтетический вариант → переписывание ожидания → снятие проверок одной фразой → принятие → отмена запуска → запуск → фон и сообщение с результатом → провал → повтор случая на новой версии → сравнение («исправлено»). Отдельно: терминал 64 колонки, длинный русский текст, многострочная вставка с путём, `Ctrl+O` без потери набранного текста, ошибки инструментов, отмена подтверждений, четыре переоткрытия сессии. Записи `.agent-lab` проверялись после шагов; права 0600.

## Не проверено вживую

- Остановка фонового прогона словами — только автотестом (учебный прогон короче окна остановки).
- Субъективная приёмка владельцем.

## Известные ограничения

- Проверка «слова владельца или модели» — эвристика по началам слов; ошибается в сторону лишнего native-подтверждения.
- Ожидание, которого нет в материалах владельца, проверяющий оставляет спорным: это правило измерений, не UX.
- Переоткрытая сессия показывает у старых строк только подпись; содержимое — по повторной просьбе.
