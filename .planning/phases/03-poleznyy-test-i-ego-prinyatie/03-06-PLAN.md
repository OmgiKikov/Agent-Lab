## Flagged assumptions resolved by this plan

- **FA-DISC-01:** 0 диалогов отклоняются до calls; 1..300 включительно допустимы; 301 отклоняется; byte/char caps сохраняются.

- **FA-DISC-06:** saved ready run заранее показывает fixed reply-channel; обычное owner «да» подтверждает его вместе с exact hypothesis и создаёт ровно один тест.
- **FA-DISC-07:** empty, boundary, adjacency, stable ordering, no-duplicate и precision cases являются блокирующими tests; все counts — точные integers, не оценки accuracy.
