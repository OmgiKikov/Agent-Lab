<interfaces>
Existing import boundary: readData(file, 'dialogues') accepts a non-empty JSON array or ordered non-empty JSONL, validates dialogueSchema, caps the file and dialogue count, and reports a malformed JSONL line number.

Existing domain types: Dialogue.messages is an ordered array of user/assistant content; Scenario carries provenance, user opening/script, checks, successCriteria and metrics; Trial carries ordered TraceEvent rows, observation, checks, assessments and usage.

New contract required here: dialogueToScenario(dialogue, criteria) receives expected goal/successCriteria explicitly; dialogueToTrial(dialogue, scenario, revisionId) maps every original message directly to {seq,type,text}. Neither converter may derive expected behavior from assistant text or dialogue.outcome.

Existing application boundary: ExperimentLab mutations use ensureIdle/change, launch, checkpoint, ExperimentStore.appendTrace, structuredClone snapshots, and immutable reassessment. Keep score inside that boundary.
</interfaces>
