<objective>
Make the positive control measurable on the real acquiring agent without breaking the repeat diff (gap TRUST-04, success criterion 5 of 01-VERIFICATION.md).

Why this code change is needed (planning-time read-only probe, ids and numbers only):
- The candidate `ae812a24-8f12-4190-b666-18c26c83a807` gets the same first agent reply in all five stored runs (sha256 prefix `86107f01`, 291 characters, no question mark). This is not the stock reply `d4738c00`.
- In `fae4ee59` and `a92fd6ae` the conversation ended after that reply. Goal votes: `a92fd6ae` pass/pass; `fae4ee59` pass/fail.
- In the three live phase-1 attempts the reactive simulator kept talking after the reply. The judge then flagged the simulator (`simulator_unclear` / `simulator_deviated`), so the control stayed unmeasured.
- A control exists to check the judge and the connection, not the simulator. Running it as one turn (the opening plus the agent's first reply) removes the simulator from the control (`metricApplies` drops `user_fidelity` when no simulator event exists).
- This changes the control card, so `compareRuns` must stop comparing control situations. Otherwise every repeat with a control becomes «несравнимы».

Decisions implemented (phase-1 CONTEXT labels as used in 01-09 / 01-10):
- CTX-10: the control is a real dialogue the agent handles. This plan makes it measurable. The live proof and the labelled synthetic fallback are in 01-12.
- CTX-11: the control never enters «N из M». This plan extends that to the repeat diff.
- CTX-13: the control is marked on the record, and old records and their `draftHash` stay untouched. No marker goes inside the card. The only card change is the existing `maxFollowUps` field, and only on new drafts that will run.
- Claude's discretion (planner): a control always runs as one turn, and the rule applies in `repeat` and `loadSuite` only. Reassessment re-judges stored transcripts and never changes cards.
- Orchestrator: TRUST-04 is unchecked until live evidence closes the gap.

Purpose: the mechanism half of the TRUST-04 gap closure. 01-12 does the live half.
Output: `oneTurnControls`, the control-free `compareRuns`, the stability identity skip, the Pi description, tests, and REQUIREMENTS.md with TRUST-04 unchecked.
</objective>
