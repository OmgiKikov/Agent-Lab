<objective>
Give the judge audit its own file next to the run record and leave a small receipt on the trial, so records stop growing toward the 50 MB read limit, while old records keep working.

- CTX-23 Full audit in a sidecar `{id}.judge/{trialId}.json` (atomic write); a small receipt with hashes on the trial; `hasCompleteJudgment` keeps the old path for records with the full audit; the journal gets the audit once per finished vote set (this plan provides the `final` signal; 01-06 wires it); reports stop embedding it (01-07); the trial schema gets an optional field; `dist/` is rebuilt from a snapshot before new records are written (01-10).
- CTX-26 `JUDGE_PROTOCOL` unchanged.

Purpose: the storage half of TRUST-08.
Output: receipt contract and verifier, sidecar store methods, final-judgment signal.
</objective>
