# Агент эквайринга

[aigw-observed.py](aigw-observed.py) — адаптер `kind: "command"` для локального `aigw-local`:
отвечает через его HTTP API и дополнительно читает состояние из PostgreSQL и связанные трассы,
чтобы Lab проверял действия агента, а не его слова.

Запускается интерпретатором из `.venv` самого `aigw-local`, путь к проекту — единственный аргумент.
Подключение к базе берётся из переменных `POSTGRES_*` и `DB_PASS` окружения агента.
