# Агент эквайринга

[aigw-observed.py](aigw-observed.py) — адаптер `kind: "command"` для локального `aigw-local`:
отвечает через его HTTP API и дополнительно читает состояние из PostgreSQL и связанные трассы,
чтобы Lab проверял действия агента, а не его слова.

Запускается интерпретатором из `.venv` самого `aigw-local`, путь к проекту — единственный аргумент.
Подключение к базе берётся из переменных `POSTGRES_*` и `DB_PASS` окружения агента.

Как читать исход ответа, знает сам `aigw-local` (`local/agent_lab_target.py`): адаптер берёт оттуда
`ask` и функцию наблюдения — публичную `observed`, а пока её нет, `_observed`. Приватное имя — не
выбор, а вынужденная мера: репозиторий испытуемого обвязка не меняет, а копия этой функции здесь
разошлась бы с оригиналом молча. Если в `aigw-local` нет ни одной из двух, адаптер скажет об этом
сразу, а не упадёт на импорте.
