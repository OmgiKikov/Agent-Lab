# Покрытие prototype 2.html

7 октября 2026. Ветка `codex/prototype-ux-current`, основа `origin/master` — `93603dd7`.

## Итог

Реализованы рабочие сценарии HTML: несколько датасетов, версии наборов судьи, редактор критериев, три режима проверки, единый запуск и раздельные результаты, настройки контекста и редактирование агента. Сохранены подробные доказательства, ответы людей, серьёзность ошибок, история и симуляции из master.

Это не копия демонстрационных чисел HTML. Запуски используют существующий backend, выбранные данные и правила. Произвольное среднее по разным режимам заменено отдельными результатами. Служебный переключатель демо-MVP и сброс демонстрационных данных в рабочее приложение не переносились.

## По пунктам

| Возможность HTML | Реализация |
| --- | --- |
| Создание и переключение агентов | Сохранено из master; данные изолированы по агентам. |
| Изменение имени и описания | Карточка «Агент», кнопка «Изменить»; ID, ссылки и база не меняются. |
| ИФТ-endpoint | Сохранено подключение по HTTP и проверка связи. |
| Репозиторий по URL | HTTPS/HTTP/SSH URL, управляемая локальная копия, обновление при «Прочитать код». Доступ берётся из настроенного Git. Локальная папка тоже поддерживается. |
| Ручной список Tools | «Контекст для проверки» в карточке агента; список поступает судье как доступные инструменты, а не как доказательство их вызова. |
| Индекс IDP | Адрес, индекс, embedder и фильтр; проверка связи, реальное получение пассажей, ошибки и источники в результате. Адаптер проверен по HTTP-контракту локального агента; реальный банковский контур не проверялся. |
| Несколько именованных датасетов | Датасеты сосуществуют; выбор, переименование, архив и восстановление после перезагрузки. |
| Выбор данных перед запуском | Общий выбор датасета для проверок. Каждый запуск сохраняет ссылку на исходный датасет и снимки доказательств. |
| Просмотр разговоров | Постраничный список и полный исходный диалог до запуска модели. |
| CSV / JSON | Поддерживаются вместе с XLSX / JSONL. Формат описан в загрузке. |
| Tone of voice на датасете | Существующий мастер и новый общий экран запуска. |
| Точность на датасете | Критерии из кода либо выбранный пользовательский/встроенный набор правил. |
| Загрузка правил | MD, TXT, DOCX, вставка текста; сохранение как именованного набора. |
| Генерация критериев | Сохранена настоящая генерация Tone of voice из документа. Доступна из библиотеки выбранного набора. |
| Ручной редактор критериев | Добавление, изменение, удаление, условия применения и допустимые ответы. |
| Наборы и версии судьи | Выбор перед запуском. Редактирование создаёт новую версию; встроенный набор редактируется через копию. |
| Собственные правила точности | Поддерживаются независимо от репозитория. |
| Скачать правила | Markdown конкретной сохранённой версии или текущих критериев. |
| Версия агента | Необязательная версия/метка в параметрах запуска. Сообщённая стендом версия хранится отдельно в результатах живых режимов. |
| Режим «Датасет» | Оценивает записанные ответы без обращения к агенту. |
| Режим «ИФТ · вопросы» | Отправляет исходные реплики клиента, не подменяя их синтетическим клиентом. Сохраняет исходный разговор и новые ответы рядом. |
| Режим «ИФТ · симуляции» | Существующий симулятор; при необходимости сначала создаются оценка и сценарии выбранной проверки. |
| Несколько режимов одним запуском | Единый запуск с выбранными режимами, прогрессом, остановкой, продолжением и повтором. Успешные режимы не повторяются при продолжении прерванного запуска. |
| Правила/карточки симуляций | Существующие сценарии с источником, условиями, критериями и результатами; привязаны к данным и проверке. |
| История | История запусков режимов и прежняя история сохранённых оценок. Старые диалоги и правила доступны после смены данных и критериев. |
| Отчёт | Итоги по каждому режиму, нарушения и охват, подробные доказательства и пары ответов; без среднего по несопоставимым данным. |
| Сравнение | Пары отмечаются как улучшение/ухудшение только при сопоставимых критериях, судье, контексте и источниках знаний. |
| Поиск, мобильность, клавиатура | Сохранены; добавленные формы используют общие компоненты и проверены на узком экране. |
| Демо-MVP и сброс демо | Не перенесены: это средства показа прототипа, а не пользовательский процесс работы с реальными данными. |

## Проверка

- Полный `sh bin/check.sh`: **466 тестов**, Ruff, ESLint, Prettier, TypeScript и production build.
- Новые регрессии: сосуществование датасетов, архив/восстановление, перенос прежней выгрузки, изоляция агентов, независимость результатов Tone of voice от изменений точности, неизменность старых версий и отчётов, конфликт редактирования правил, CSV/JSON, точный повтор клиентских реплик, остановка и продолжение, несовместимый контекст и знания.
- Интеграционный тест проходит настоящие процессы публикации оценки, воспроизведения вопросов и симуляции; внешние агент и модель заменены контролируемыми тестовыми ответами.
- В браузере: запуск всех трёх режимов, пары ответов, ручной редактор, v1 → v2, скачивание v2, второй датасет из CSV, архив после перезагрузки, восстановление, изменение имени/описания с прежним URL, точность по набору без репозитория, 375 px.
- IDP: проверены тело запроса, индекс, аутентификация, маршрутизация и чтение возвращённых пассажей через тестовый HTTP transport. Работа с реальным банковским endpoint и его сертификатами требует проверки в доступном контуре.
- Для браузерного демо используется отдельная база `/tmp/agent-lab-ux-current` и тестовые агент/судья. Оценки демо не являются оценкой реального агента.
