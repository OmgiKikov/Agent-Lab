# Демо Agent Lab

    sh bin/start.sh

Открыть http://127.0.0.1:5899/lab. Интерфейс, разговоры и результаты обслуживает один Python backend.

## Основной путь

1. «Агент»: задать адрес агента, EPK и репозиторий; проверить связь с моделями и агентом.
2. Собрать источники из кода агента.
3. «Логи»: загрузить Excel или JSONL и запустить аудит.
4. «Критерии»: посмотреть основания правил, оценённые разговоры и цитаты доказательств.
5. «Диалоги»: открыть полный реальный разговор напрямую из данных Lab.
6. «Сценарии»: собрать карточки, выбрать агента, типы клиентов и число повторов.
7. «Судья»: проверить спорные оценки вручную и переоценить сохранённый прогон.

Цифры в демо берутся из выбранного набора данных. UNKNOWN означает, что вывод не доказан;
это не выполнение критерия. Если события инструментов или статьи не наблюдаются,
их отсутствие нельзя заменять цитатой текстового ответа.

Через OpenRouter основной и второй судьи используют настроенные модели; на банковском
шлюзе автоматический выбор может назначить одну модель обоим. Их согласие в этом режиме
не является сравнением двух независимых моделей.

## Если что-то не работает

- Запуск и ошибка сборки: смотреть вывод bin/start.sh.
- Во время разработки backend слушает :5901, Vite — :5900.
- Если порт занят прежним Workshop, остановить его обычной командой из прежней установки
  или задать другой LAB_PORT. Новый запуск не завершает чужие процессы.
- Старые JSON/JSONL импортируются отдельно, после резервной копии и при остановленном backend;
  команда описана в README.
- История ~/.raindrop/ остаётся прежней; текущий Lab не зависит от её наличия.
