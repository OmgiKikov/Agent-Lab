Актуальные документы:

- [README](../../README.md) — основной пользовательский цикл;
- [WORKFLOWS](../WORKFLOWS.md) — пошаговый запуск;
- [REFERENCE](../REFERENCE.md) — форматы и подключение;
- [EVALS-METHOD](../EVALS-METHOD.md) — границы автоматической оценки;
- [CONTEXT](../../CONTEXT.md) — словарь MVP.
