# MVP-срез Agent Lab: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Довести Agent Lab до MVP «проверка и повторное тестирование» до демо 21.09.2026: честный первый экран с вердиктом человека, оценка записанных диалогов, диета карточки бизнес-сценария, удаление исследовательского слоя и доски, проверка трёх обещаний на втором агенте.

**Architecture:** Швы не меняются: `Runtime` для ролей модели, `TargetSession` для испытуемого, `ExperimentLab` для фаз и хранения, чистые функции над записью для экрана, расширение Pi для человека. Записанные диалоги входят как production-карточки с одной scripted-попыткой из файла и оцениваются существующим `reassess`. Схема хранения остаётся совместимой: удаляемые поля становятся необязательными, старые записи читаются.

**Tech Stack:** TypeScript (Node ≥ 22.19, ESM, `tsc`), `node:test` через `tsx`, zod 4, typebox, Pi SDK `@earendil-works/pi-coding-agent` 0.85.1. Новых зависимостей нет.

**Spec:** `docs/superpowers/specs/2026-09-15-mvp-cut-design.md` (коммит `69a11a0`).

## Global Constraints

- Язык: пользовательские строки, документация и сообщения об ошибках по-русски; код, идентификаторы, комментарии в коде и сообщения коммитов по-английски.
- Термин продукта: «карточка бизнес-сценария» (в коде `Scenario`). «Карточка пользователя» в новых строках не используется.
- Принцип: минимально то, что нужно, и аккуратно. Ничего сверх задачи; каждая задача заканчивается зелёными тестами и коммитом.
- Обещания продукта: P1 первый экран за 30 минут; P2 за час человек разбирает 15 диалогов с основаниями, экран показывает автоматический счёт и «разобрано человеком K из D» рядом; P3 повтор тех же карточек называет «починилось / сломалось / несравнимо».
- Тесты во время разработки: `npx tsx --test test/<file>.test.ts` (без пересборки `dist`). Полный прогон: `npx tsx --test test/*.test.ts`. Типы: `npx tsc --noEmit -p tsconfig.json`. Расширения импортируют `../dist/*.js`, поэтому перед тестами расширений и `npm run typecheck` нужен `npm run build`; перед `npm run build` проверить `ps aux | grep 'dist/cli.js'`: если в этом worktree идёт чужой прогон из `dist`, дождаться его конца.
- В этом worktree работает параллельная сессия. Перед каждым коммитом `git status --short`; в коммит добавлять только файлы своей задачи, по именам.
- Схема хранения: поля не удаляются из `experimentSchema`, только становятся `.optional()` с комментарием `legacy, removed 2026-09-…`; старые JSON в `.agent-lab` должны читаться.
- Протокол судьи: любое изменение того, что судья видит на входе, поднимает `version` в `JUDGE_PROTOCOL` (`src/judge.ts`).
- Коммиты завершаются строкой `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.

```ts
/** Rubric outcomes stay separate from objective checks everywhere they are presented. A human verdict on a criterion is the reference: «ошибся тест» removes the criterion, pass and fail replace the judge, unknown stays unknown. */
export function agentRubricResult(scenario: Scenario | undefined, trial: Trial, reviews: HumanReview[] = []): 'pass' | 'fail' | 'unknown' | undefined {
  const metrics = scenario?.metrics?.filter(m => m.subject === 'agent') ?? [];
  if (!metrics.length) return undefined;
  const latest = latestHumanReviews({ trials: [trial], humanReviews: reviews });
  const results = metrics.flatMap(m => {
    const human = latest.get(`${trial.id}|metric:${m.id}`)?.verdict;
    return human === 'invalid' ? [] : [human ?? trial.assessments?.find(a => a.metricId === m.id)?.result];
  });
  if (!results.length) return undefined;
  return results.includes('fail') ? 'fail' : results.every(r => r === 'pass') ? 'pass' : 'unknown';
}
export function isAgentFailure(record: Experiment, trial: Trial): boolean {
  const scenario = record.scenarios.find(s => s.id === trial.scenarioId);
  return measurementUsable(scenario, trial, record.humanReviews) && (trial.outcome === 'fail'
    || agentRubricResult(scenario, trial, record.humanReviews) === 'fail');
}
```

```ts
export interface AnnotationTarget { label: string; ids: { metricId?: string; checkId?: string }; trialIds: string[] }
/** What a person can put a verdict on: this dialogue, a named cause (all its dialogues at once, on their one shared failed criterion), one criterion, one check. */
export function annotationTargets(record: Experiment, trial: Trial): AnnotationTarget[] {
  const scenario = record.scenarios.find(s => s.id === trial.scenarioId);
  const failedAgentMetrics = (t: Trial) => new Set((record.scenarios.find(s => s.id === t.scenarioId)?.metrics ?? [])
    .filter(m => m.subject === 'agent' && t.assessments?.some(a => a.metricId === m.id && a.result === 'fail')).map(m => m.id));
  const causes = (record.failureModes ?? []).filter(mode => mode.trialIds.includes(trial.id)).map(mode => {
    const trials = mode.trialIds.map(id => record.trials.find(t => t.id === id)).filter((t): t is Trial => !!t);
    const shared = [...failedAgentMetrics(trial)].filter(id => trials.every(t => failedAgentMetrics(t).has(id)));
    return { label: `Причина · ${safeText(mode.name)} · ${trials.length} диалогов${shared.length === 1 ? ` · критерий ${shared[0]}` : ''}`,
      ids: shared.length === 1 ? { metricId: shared[0]! } : {}, trialIds: trials.map(t => t.id) };
  });
```

```ts
/** A recorded dialogue as a production card: the real opening, every later user message as the script, criteria supplied by the goals role or the owner. */
export function dialogueToScenario(dialogue: Dialogue, criteria: { goal: string; successCriteria: string }): Omit<Scenario, 'split'> {
  const users = dialogue.messages.filter(m => m.role === 'user').map(m => m.content);
  if (!users.length) throw new Error(`Диалог ${dialogue.id} не содержит реплик пользователя.`);
  return {
    id: dialogue.id, familyId: dialogue.id, title: criteria.goal.slice(0, 200), requirementIds: [], provenance: 'production', tier: 'regression',
    user: { goal: criteria.goal, facts: 'Только то, что реальный пользователь сказал в записанном диалоге.', behavior: 'Записанный диалог: реплики пользователя воспроизводятся дословно.',
      opening: users[0]!, script: users.slice(1), maxFollowUps: users.length - 1 },
    initialState: { records: {}, writableFields: [], transientFailures: 0 }, checks: [], successCriteria: criteria.successCriteria,
    assumptions: [`Записанный диалог ${dialogue.id}: результаты действий агента не наблюдались, оценены только реплики.`],
    metrics: [{ ...goalAttainment }, { ...replyQuality }],
  };
}
/** The recorded conversation as one scripted attempt: nothing was executed, so nothing was observed. */
export function dialogueToTrial(dialogue: Dialogue, scenario: Omit<Scenario, 'split'>, revisionId: string): Trial {
  return {
    id: dialogue.id, revisionId, scenarioId: scenario.id, familyId: scenario.familyId, repeat: 0, userMode: 'scripted', split: 'dev', manifestHash: '',
    outcome: 'ungraded', reason: 'Записанный диалог: агент и симулятор не вызывались.', checks: [],
    events: dialogue.messages.map((m, seq) => ({ seq, type: m.role, text: m.content })),
    initialState: scenario.initialState, finalState: scenario.initialState, usage: emptyUsage(), elapsedMs: 0,
    observation: { state: 'missing', tools: 'partial' },
  };
}
```

```ts
  async score(raw: CreateInput): Promise<Experiment> {
    this.ensureIdle();
    const input = createInputSchema.parse({ ...raw, workflow: 'evaluate', scenarioCount: 0, goldenCases: [] });
    if (!input.dialogues.length) throw new Error('Для оценки записанных диалогов нужен хотя бы один диалог.');
    const record = this.newRecord(input);
    record.message = 'Читаю записанные диалоги и готовлю критерии.';
    record.limitations.push('Записанные диалоги: агент и симулятор не запускались; результаты действий агента не наблюдались, оценены только реплики.');
    await this.launch(record, async ctx => {
      const runtime = await this.runtime(record);
      const grounding = await runtime.prepare({ task: record.task, sources: structuredClone(record.sources), workflow: 'evaluate', scenarioCount: 0, targetKind: record.target.kind }, ctx);
      const hasPrompt = record.sources.some(s => s.kind === 'prompt');
      const scenarios: Omit<Scenario, 'split'>[] = [];
      for (const dialogue of record.dialogues) {
        ctx.signal.throwIfAborted();
        const [goal] = runtime.goals ? await runtime.goals({ task: record.task, sources: structuredClone(record.sources), dialogues: [structuredClone(dialogue)], profiles: [] }, ctx) : [];
        const opening = dialogue.messages.find(m => m.role === 'user')?.content ?? '';
        const scenario = dialogueToScenario(dialogue, goal ? { goal: goal.goal, successCriteria: goal.successCriteria }
          : { goal: dialogue.goal ?? opening.slice(0, 200), successCriteria: dialogue.goal ?? `Пользователь получил ответ по существу запроса: «${opening.slice(0, 200)}».` });
        if (hasPrompt) scenario.metrics!.unshift({ ...promptCompliance });
        scenarios.push(scenario);
      }
      const prepared = validatePreparation({ ...grounding, scenarios }, record.sources, 'evaluate');
      Object.assign(record, { requirements: prepared.requirements, questions: prepared.questions, scenarios: prepared.scenarios });
      const baseline = revision(prepared.agent, null, 'Agent configuration whose recorded dialogues are scored.');
      record.revisions.push(baseline); record.selectedRevisionId = baseline.id;
      record.reviewedAt = new Date().toISOString(); record.reviewMode = 'automated';
      record.manifestHash = measurementHash(record);
      for (const dialogue of record.dialogues) {
        const trial = dialogueToTrial(dialogue, record.scenarios.find(s => s.id === dialogue.id)!, baseline.id);
        trial.manifestHash = record.manifestHash;
        for (const event of trial.events) this.store.appendTrace(record.id, trial.id, event);
        record.trials.push(trial);
```
