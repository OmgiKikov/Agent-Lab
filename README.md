# Agent Lab

Проверка качества ИИ-агента эквайринга СберБизнес: от кода и логов агента до одной метрики качества.

1. **Подключение агента** — HTTP-ручка на ИФТ или запуск из репозитория.
2. **Контекст агента** — промпты, инструменты, база знаний из кода агента → правила проверки с цитатами.
3. **Аудит диалогов** — LLM-судья проверяет реальные разговоры из логов по правилам.
4. **Тестовые карточки** — ситуации клиентов из логов с тестовыми данными и критериями.
5. **Тестирование агента** — искусственный клиент ведёт диалоги с агентом.
6. **Оценка LLM-судьёй** — вердикт по каждому критерию с цитатой агента, сверка с базой знаний, второй судья.
7. **Метрика качества** — доля диалогов без ошибок, сравнение версий, частые причины ошибок.

## Запуск на маке

    sh lab/start.sh

Открывает http://127.0.0.1:5899/lab — раздел Agent Lab внутри Raindrop Workshop.
Исходники Workshop с разделом Agent Lab — в `workshop/` (Raindrop Workshop 0.1.21, MIT);
`lab/workshop/build.sh` собирает и ставит интерфейс, `restore.sh` возвращает обычный Workshop.

## Команды

    python -m lab sources --repo ~/Desktop/aigw-local   # промпты и инструменты из кода агента
    python -m lab discover --count 100                  # аудит диалогов (--replan — новые правила)
    python -m lab cards                                 # тестовые карточки
    python -m lab run --target local-http --repeats 2   # тестирование: local-http | local-code | prod
    python -m lab rejudge                               # переоценка без запуска агента
    python -m lab bundle                                # архив для рабочего компьютера (ИФТ)

## Рабочий компьютер (ИФТ)

`python -m lab bundle` → архив с кодом, данными и `run-prod.bat` / `run-prod.sh`; инструкция —
`lab/WORK-COMPUTER.md`. Шлюз моделей — по рабочему сертификату (`certs/` или `~/.agent-lab/gateway.json`).

Данные (логи, карточки, прогоны, адреса) лежат в `lab/data/` и в репозиторий не попадают.
Шпаргалка к демо: `docs/agent-lab-demo.md`.
