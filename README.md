# LangWatch для проверки диалогов

Этот проект переходит на [LangWatch](https://github.com/langwatch/langwatch). Рабочий продукт открывается по адресу **http://localhost:5560**. Локальное пространство «Диалоги» создаётся автоматически; заполнять форму регистрации не нужно.

## Запуск

Откройте терминал в этой папке и выполните:

```bash
./scripts/start-langwatch.sh
```

На первом запуске установка может занять несколько минут. Затем откройте http://localhost:5560. Если браузер попросит войти, команда `./scripts/show-local-login.sh` покажет данные только вашего локального пользователя. Для остановки нажмите `Ctrl+C` в терминале запуска.

Исходный код LangWatch лежит в папке `langwatch/`. Он загружается автоматически и остаётся локальной копией. Данные и секреты хранятся в `langwatch/.local/` и не отправляются в GitHub. Локальный запуск отключает отправку служебной статистики LangWatch.

## Архив Agent Lab

Код прежнего Agent Lab сохранён в истории Git под меткой `archive/agent-lab-2026-09-27`. Его локальные результаты сохранены в `.local-archive/agent-lab-2026-09-27/`. Активная ветка больше не запускает Agent Lab.

## Разговоры и проверки

Все 866 разговоров уже доступны в наборе [«Диалоги из банка — точный текст»](http://localhost:5560/local-dev-project-se7hbx/datasets/dataset_nfqYqIRfcPoA2_yA0JEdo). Для каждой записи текст и остальные поля посимвольно сверены с исходной выгрузкой. Повторяющиеся реплики и интерфейсные вставки сохранены. Для переноса использован JSONL: пробная загрузка CSV испортила 11 русских фрагментов и была удалена.

Из присланных документов получен [справочник из 178 уникальных статей](http://localhost:5560/local-dev-project-se7hbx/datasets/dataset_Pd614NaYKeaVLCwNvAfnK). Тексты сверены после загрузки. В документах также 2103 встроенных изображения; сведения, которые есть только на них, пока не входят в текстовую проверку.

Для начала создан [набор из трёх разговоров с подходящими выдержками](http://localhost:5560/local-dev-project-se7hbx/datasets/dataset_xlcxjOvH7vOGcneXCOH7-) и [эксперимент с оценщиком фактов](http://localhost:5560/local-dev-project-se7hbx/experiments/workbench/pFvqv9kW). Оценщик различает подтверждённый ответ, доказанную ошибку и нехватку источника. Он ещё не запускался: в LangWatch не подключена модель. Пока результатов проверки правильности нет.
