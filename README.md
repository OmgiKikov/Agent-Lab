# Agent Lab

Проверка качества ИИ-агента эквайринга СберБизнес: от кода и логов агента до одной метрики качества.
Всё делается в интерфейсе — разделе **agent lab** внутри Workshop.

| Шаг | Что происходит |
|---|---|
| 1. Агент | Адрес агента на ИФТ, EPK клиентов, код агента. Из кода собираются промпты и инструменты — источники правил. |
| 2. Логи | Загружается выгрузка диалогов из Excel. LLM-судья проверяет реальные разговоры по правилам с цитатами из промптов. |
| 3. Сценарии | Из логов собираются тестовые карточки: ситуация клиента, критерии, данные в системах банка. |
| 4. Прогон | Искусственный клиент разговаривает с агентом, судья и второй судья оценивают каждый разговор. |
| 5. Точность | Доля разговоров без ошибок, согласие судей, устойчивость на повторах, частые причины ошибок. |

## Запуск

    sh bin/start.sh

Откроется http://127.0.0.1:5899/lab. Скрипт один для любого компьютера: ставит зависимости, собирает или скачивает
Workshop, поднимает модели и Agent Lab. Нужны [uv](https://docs.astral.sh/uv/) и `git`.

**Модели судьи и клиента** выбираются сами:

- лежат сертификаты шлюза банка в `certs/` — через шлюз (новейшая GLM из его каталога);
- нет — через OpenRouter: мосты на Pi (`bridge/`), нужен Node.js 22+ и вход в Pi с ключом OpenRouter.

**Рабочий компьютер.** Склонировать репозиторий, положить в `certs/`:

- `url.txt` — адрес шлюза моделей, одна строка;
- сертификат и ключ (`.pem`/`.crt` и `.key`) или один `.p12`/`.pfx`, пароль к нему — в `password.txt`;
- `ca.pem` или `root.pem` — корневой сертификат банка, если без него шлюз не пускает.

Затем `sh bin/start.sh`. На шаге «агент» указать адрес ИФТ-ручки и EPK, нажать «проверить модели» и «проверить связь».

## Устройство

    bin/          запуск (start.sh), сборка Workshop (build-workshop.sh), публикация сборки (release-workshop.sh)
    lab/          Agent Lab: Python, API раздела на :5901
      api.py        HTTP API для интерфейса
      agents/       агенты под проверкой: HTTP-контракт, запуск из кода, данные сценария для заглушек
      context/      что агент знает: промпты и инструменты из кода, база знаний, готовые ответы
      logs.py       выгрузка диалогов из Excel
      discover.py   аудит логов: правила из источников, вердикты по разговорам
      cards.py      тестовые карточки
      simulate.py   прогон: искусственный клиент ↔ агент, трейсы в Workshop
      judge.py      судья и второй судья, вердикт только с цитатой агента
      metric.py     точность и её проверка
      llm/          модели: шлюз банка по сертификатам или OpenAI-совместимый endpoint
      prompts.py    все промпты
    bridge/       мост OpenAI → Pi для OpenRouter
    workshop/     Workshop: сервер и интерфейс, наш форк Raindrop Workshop (MIT), раздел agent lab
    docs/demo.md  шпаргалка к демо

Данные — логи, карточки, прогоны, настройки, адреса — лежат в `data/`, сертификаты в `certs/`;
в репозиторий они не попадают. Трейсы Workshop — в `~/.raindrop/`.

Проверка кода: `uvx ruff check` и `uvx ruff format --check` (Python), `bun x tsc --noEmit` в `workshop/` и `workshop/app/`.
